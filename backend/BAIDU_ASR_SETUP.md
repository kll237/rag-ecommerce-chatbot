# 百度语音识别API配置指南

本项目使用百度语音识别API实现语音输入识别文本功能。

## 功能说明

- **优先方案**：百度语音识别API（云端服务，准确度高）
- **备用方案**：Whisper本地模型（离线可用，需安装依赖）
- **演示模式**：当以上方案都不可用时，返回模拟文本

## 快速开始

### 1. 开通百度语音识别服务

1. 访问百度智能云：https://cloud.baidu.com/
2. 注册/登录账号
3. 进入控制台，搜索"语音识别"或访问：https://console.bce.baidu.com/ai/#/ai/speech/overview/index
4. 点击"立即使用"或"免费试用"

### 2. 创建应用

1. 在语音识别控制台，点击"创建应用"
2. 填写应用信息：
   - **应用名称**：例如"电商客服系统"
   - **应用描述**：例如"RAG电商客服系统语音识别"
   - **应用类型**：选择"语音技术"
3. 提交后等待审核（通常即时通过）

### 3. 获取API凭证

创建应用成功后，会显示以下信息（请妥善保管）：
- **AppID**：应用ID（纯数字，如：12345678）
- **API Key**：API密钥（以字母开头）
- **Secret Key**：密钥（混合字符串）

### 4. 配置环境变量

在 `backend/.env` 文件中添加以下配置：

```bash
# 百度语音识别配置（每日 5 万次调用免费）
BAIDU_ASR_APP_ID=你的AppID
BAIDU_ASR_API_KEY=你的API_Key
BAIDU_ASR_SECRET_KEY=你的Secret_Key
```

**配置示例**：
```bash
BAIDU_ASR_APP_ID=20260120002543655
BAIDU_ASR_API_KEY=aBcDeFgHiJkLmNoPqRsTuVwXyZ
BAIDU_ASR_SECRET_KEY=1234567890abcdef1234567890abcdef
```

### 5. 重启服务

配置完成后，重启后端服务使配置生效：

```bash
# Windows
start.bat

# 或手动重启
cd backend
python start.py
```

## 技术参数

### 音频格式要求

- **支持格式**：PCM、WAV、AMR、M4A、AAC、MP3
- **采样率**：推荐16000Hz（16kHz）
- **位深度**：16bit
- **声道数**：单声道（Mono）
- **音频时长**：不超过60秒
- **音频大小**：不超过10MB

### API调用流程

1. 使用API Key和Secret Key获取Access Token
2. 使用Access Token调用语音识别接口
3. 返回识别结果（JSON格式）

### 识别结果示例

```json
{
  "err_no": 0,
  "err_msg": "success",
  "corpus_no": "678534234235",
  "sn": "12345678901234567890",
  "result": ["你好，我想查询一下我的订单状态"],
  "confidence": 0.95
}
```

## 故障排查

### 问题1：返回"未配置百度语音识别凭证"

**原因**：环境变量未配置或配置错误

**解决方案**：
1. 检查 `backend/.env` 文件是否存在
2. 确认三个配置项都已填写：
   - `BAIDU_ASR_APP_ID`
   - `BAIDU_ASR_API_KEY`
   - `BAIDU_ASR_SECRET_KEY`
3. 重启后端服务

### 问题2：返回"获取access_token失败"

**原因**：API Key或Secret Key错误

**解决方案**：
1. 登录百度智能云控制台
2. 检查应用信息中的API Key和Secret Key
3. 确认复制时没有多余的空格或换行
4. 重新配置环境变量并重启服务

### 问题3：识别失败，错误码52001

**原因**：请求超时

**解决方案**：
1. 检查网络连接
2. 尝试使用代理或VPN
3. 系统会自动降级到Whisper本地模型

### 问题4：识别结果不准确

**原因**：音频质量问题

**解决方案**：
1. 确保录音环境安静
2. 使用麦克风时保持适当距离（10-30cm）
3. 语速适中，发音清晰
4. 音频采样率设置为16000Hz

## 备选方案

如果百度语音识别不可用，系统会自动降级：

### 方案1：Whisper本地模型

**优点**：
- 离线可用
- 无需网络
- 准确度高

**缺点**：
- 需要安装依赖：`pip install openai-whisper`
- 首次使用需要下载模型（约75MB）
- 识别速度相对较慢

**安装方法**：
```bash
pip install openai-whisper
```

### 方案2：演示模式

**适用场景**：
- 测试和开发
- 没有配置任何语音识别服务
- 网络不可用且未安装Whisper

**特点**：
- 返回预设的模拟文本
- 不依赖任何外部服务
- 仅用于功能演示
